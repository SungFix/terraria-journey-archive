# Terraria — Journey Archive

Site de fã para acompanhar os itens pesquisados no **Modo Jornada do Terraria**, com visual inspirado na Terraria Wiki.

**Acessar o site após ativar o GitHub Pages:** https://sungfix.github.io/terraria-journey-archive/

## Funcionalidades
- Catálogo pesquisável, categorias e filtros por status
- Marcação manual de itens pesquisados e indicador de progresso
- Idiomas: português (Brasil), inglês e espanhol (traduções parciais)
- Quantidade necessária para pesquisa, quando disponível na fonte
- Exportação/importação de progresso em JSON
- Importação manual de sprites PNG por ID de item
- Layout para desktop e celular

## Como usar
Abra [index.html](index.html) em um navegador, ou use a URL do GitHub Pages após a publicação.

## Ativar GitHub Pages
Em **Settings → Pages**, selecione **Deploy from a branch**, **main**, **/(root)** e clique em **Save**.

## Notas importantes
- O site é independente, não oficial e não afiliado à Re-Logic ou à Terraria Wiki.
- O catálogo completo, as traduções e os sprites dependem de serviços externos; o site informa quando mostra apenas a amostra de 64 itens.
- O fundo e o cabeçalho ficam embutidos no arquivo HTML, mas os ícones dos itens são carregados externamente.
- O progresso é guardado no `localStorage` do navegador. Para trocar de navegador/dispositivo, faça backup em JSON.
- As imagens PNG importadas manualmente não são mantidas após recarregar.
- Terraria e seus recursos pertencem aos respectivos titulares.
